# الخطوط العربية

كلها من Google Fonts بترخيص SIL Open Font License (مجانية للاستخدام التجاري). نص الترخيص في `OFL-LICENSE.txt`.

| الملف | الاستخدام في الحلقات |
| --- | --- |
| `Lalezar-Regular.ttf` | العناوين الكبيرة |
| `Tajawal-ExtraBold.ttf` / `Tajawal-Bold.ttf` | الترجمة النصية والحوار |
| `Marhey-Bold.ttf` | أسماء الشخصيات واسم السلسلة |
| `ReemKufi-Bold.ttf` | خط كوفي احتياطي للعناوين |

ملاحظة: الملفات الصغيرة في `assets/` تُستخدم خلفيةً في وضع `--source local`، أما هذا المجلد فيُتجاهل هناك لأنه لا يحوي صوراً أو فيديو.
