# es-montage: خلّي Claude يمنتجلك الريل 🎬

مهارة لـ **Claude Code** بتاخد فيديو انت بتتكلم فيه للكاميرا، وتطلّعه ريل 9:16 جاهز للنشر:

- ✂️ **تشيل السكتات** والفراغات لوحدها.
- 📝 **تفرّغ كلامك كلمة كلمة** وتحط **كابشن عربي** متزامن، والكلمة اللي بتتقال بتنوّر بلون البراند بتاعك.
- 🎯 **عنوان هوك** فوق في أول ثانيتين (اختياري).
- 🔍 **زووم خفيف على وشك مع كل قطع**، عشان القطعات تبان مقصودة.
- 🙂 **الكلام عمره ما بيغطي وشك:** المهارة بتعرف مكان وشك في كل لقطة، وبتحط العنوان والكابشن بعيد عنه.
- 🎵 **موسيقى تحت صوتك** (اختياري، من ملف عندك).
- 🔊 **الصوت متظبط** على مستوى إنستجرام وتيك توك.
- 📄 **ملف SRT** للكابشن.

كل ده بيحصل **على جهازك**، ومفيش فيديو بيترفع لأي حتة.

---

## محتاج إيه على جهازك
| الحاجة | ليه | إزاي (ويندوز) | إزاي (ماك) |
|---|---|---|---|
| **Claude Code** | هو اللي بيشغّل المهارة | محتاج اشتراك Claude Pro أو أعلى | نفس الكلام |
| **Node.js 18+** | عشان Remotion | `winget install OpenJS.NodeJS.LTS` | `brew install node` |
| **ffmpeg** | القص والصوت | `winget install Gyan.FFmpeg` | `brew install ffmpeg` |
| **Python 3.10–3.12** + Whisper | تفريغ الكلام | من python.org، وبعدها `pip install -U openai-whisper` | نفس الكلام |
| OpenCV (اختياري) | يبعد الكلام عن وشك | `pip install opencv-python-headless` | نفس الكلام |

مش لازم تفتكر الجدول ده. Claude هيشيّك على جهازك في أول مرة، ويقولك بالظبط إيه الناقص.

---

## التسطيب (مرة واحدة)
1. فك الضغط عن الملف.
2. حط فولدر `es-montage` كله في فولدر المهارات بتاع Claude:
   - **ويندوز:** `C:\Users\<اسمك>\.claude\skills\es-montage`
   - **ماك:** `~/.claude/skills/es-montage`
3. افتح Claude Code من جديد.

## الاستخدام
افتح Claude Code في الفولدر اللي فيه الفيديو، واكتبله مثلاً:

```
منتجلي الفيديو ده: my-video.mp4
لوني ليموني #C9FF2F، شيل السكتات، حط كابشن عربي على كل كلمة،
وحط فوق عنوان «3 أدوات هتغيّر شغلك»، والموسيقى من music.mp3 تحت صوتي.
```

Claude هيسألك لو ناقصه حاجة، وبعد دقايق هيديك:
- `final.mp4`: الريل جاهز للنشر.
- `final.srt`: الكابشن لوحده.

## التعديلات
كلّمه عادي، وهو هيعدّل ويرندر تاني:
- «كبّر الكابشن وخليه أعلى شوية»
- «غيّر الخط لـ Tajawal»
- «شيل الجملة اللي بقول فيها …»
- «الموسيقى عالية، وطّيها»
- «سيب سكتات طبيعية أكتر»

وعايز تتفرج قبل الرندر؟ قوله «افتحلي البريفيو»، وهيفتحلك Remotion Studio تقلّب فيه براحتك.

---

## ملاحظات مهمة
- **أول رندر أبطأ شوية،** لأن Remotion بينزّل متصفح صغير (~100 ميجا) مرة واحدة بس.
- **الموسيقى:** استخدم موسيقى من حقك تستخدمها، والمهارة مش بتنزّل موسيقى من النت.
- **رخصة Remotion:** مجانية للأفراد والشركات اللي فيها 3 أفراد أو أقل. لو شركتك أكبر من كده، بص على remotion.dev/license.
- **أسامي الأدوات في الكابشن:** Whisper ساعات بيكتبها غلط. Claude بيراجعها قبل الرندر، بس قوله الأسامي اللي في الفيديو عشان يطلعوا صح.
