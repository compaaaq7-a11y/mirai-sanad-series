# salam-skill — مونتاج "ضربة"

مهارة محفوظة من تحليل الفيديو المرجعي `reference/reference.mp4`، وهو 46.6 ثانية بمقاس 576×1024
وإيقاع 30 فريم. تحوي ثلاثة أشياء: **الأسلوب البصري** و**الصوت وطريقة الإلقاء** و**طريقة المونتاج**،
ومعها محرك يبني الفيديو كاملاً من ستوري بورد نصي.

```
salam-skill/
  SKILL.md                  ← هذا الملف: الدليل الكامل
  reference/                ← الفيديو المرجعي + لقطات التحليل + analysis.md
  engine/salam.html         ← محرك الرسم (HTML/CSS/JS حتمي فريم بفريم)
  engine/render.mjs         ← Chromium → فريمات → ffmpeg + الصوت والمؤثرات
  engine/fonts/             ← Lalezar (العناوين) · Tajawal (الواجهات) · Oswald (REC)
  scripts/salam.py          ← tts · timeline · render · make
  examples/darba-ad.*       ← ستوري بورد الإعلان المرجعي + توقيتاته
```

## ١) طريقة العمل (اتبعها بالترتيب)

1. **افهم الطلب**: ما المنتج أو الفكرة؟ ما الكلمة التي يكتبها المشاهد في التعليقات (CTA)؟ وما المدة؟
   الافتراضي 30–45 ثانية.
2. **اكتب النص** باللهجة السعودية البيضاء حسب **وصفة النص** في القسم ٤. اعرضه على المستخدم باختصار
   إن كان المحتوى غير واضح، وإلا تابع.
3. **حوّله إلى ستوري بورد** `board.txt` حسب **صيغة الستوري بورد** في القسم ٥، مع **قواعد المونتاج**
   في القسم ٣.
4. **الصوت**، بأحد هذه الخيارات حسب المتاح:
   - **تسجيل المستخدم بصوته**. هذا أقرب شيء للأصل؛ اطلب منه أن يقرأ النص بسرعة وحماس ودون وقفات.
   - **Moknah (موصول في حساب المستخدم)**: أداة `text_to_speech` بالصوت **راشد (1779)**، خليجي
     للسوشال ميديا، والبدائل **خليفة (1780)** و**جمال (1782)**.
     الإعدادات: `{"mode":"quality","language":"ar","prerecording":1,"temperature":60}`.
     اكتب النص سطراً واحداً متصلاً وأنهِه بـ `[break_0.5]`. **استدعِ أولاً بـ `confirm_spend=false`
     واعرض التكلفة على المستخدم**، ثم نفّذ وحمّل `audio_url` بـ curl.
   - **edge-tts** المجاني: `python3 scripts/salam.py tts board.txt -o voice.mp3` (الافتراضي
     `ar-SA-HamedNeural` بسرعة `+12%`). يعمل على جهاز المستخدم وعلى GitHub Actions، ولا يعمل
     في حاويات Claude السحابية لأنها تحجب WebSocket.
5. **التوقيت**: `python3 scripts/salam.py timeline board.txt voice.mp3 -o timeline.json`
   - يستعمل faster-whisper إن توفر (`pip install faster-whisper`) لمطابقة كل كلمة بتوقيتها.
   - إن لم يتوفر يوزّع الكلمات على مقاطع الكلام المكتشفة بالطاقة. هذا دقيق مع صوت نظيف بلا موسيقى.
   - أو أعطه توقيتات يدوية بـ `--words words.json`، على شكل `[{w,start,end}]`، ويقبل عبارات كاملة.
6. **راجع لقطات ثابتة قبل الرندر الكامل** (رخيصة وسريعة):
   `python3 scripts/salam.py render timeline.json -o check.jpg --scale 0.5 --still 1,5,9,14`
   ثم انظر إليها بأداة Read: هل النص داخل الإطار؟ هل الألوان صحيحة؟ هل العنصر لا يغطي النص؟
7. **الرندر النهائي**: `python3 scripts/salam.py render timeline.json -o out.mp4`
   يأخذ قرابة 3–4 دقائق لكل 45 ثانية بدقة 1080×1920. أضف `--no-sfx` إذا كان ملف الصوت فيه
   مؤثرات أصلاً.
8. **سلّم الفيديو**: ضعه داخل المشروع أو أرسله بـ SendUserFile، وأعطِ المستخدم ملخصاً من سطرين.

**فيديو بدون تعليق صوتي** (نص + موسيقى فقط): لا تمرّر ملف صوت، وضع في رأس الستوري بورد
`@ pace=2.0 music=auto music_volume=0.5`. السرعة 2.0 كلمة في الثانية لأن القراءة أبطأ من السماع،
و`music=auto` يولّد موسيقى نبض هادئة داخل المحرك بلا إنترنت ولا حقوق. مثال: `ads/father-care/board.txt`.

اختصار للخطوتين ٥ و٧: `python3 scripts/salam.py make board.txt voice.mp3 -o out.mp4`

المتطلبات: Python 3.10+ و numpy و ffmpeg و Node 18+ و Playwright Chromium. الخطوط مضمّنة في المهارة.

## ٢) الأسلوب البصري

**الهوية اللونية** (مقيسة من الفيديو):

| الدور | اللون |
|---|---|
| أحمر العلامة | `#E3121F`، وفي الظل `#A8000F` |
| أسود الخلفية | `#0B0405` مع توهج `#6A0B10` |
| الكريمي | `#F1ECE4` |
| نص فضي/أبيض | تدرّج كروم من الأبيض إلى `#A9A9A9` مع خط أفق لامع في المنتصف |

**الخط**: عريض جداً بزوايا ناعمة: **Lalezar** للعناوين، و**Tajawal** لواجهات التطبيقات.

**النص ثلاثي الأبعاد**:
- كل كلمة مبثوقة (extrude) بعمق 10–15px نحو الأسفل.
- تعبئة متدرجة لامعة.
- ظل ناعم أسفلها.
- **انعكاس على الأرضية** يتلاشى للأسفل، وهو حاضر في كل مشهد تقريباً.

**الخلفيات الأربع**، وتتناوب ولا تتكرر خلفيتان متتاليتان إلا مع عنصر ثابت:

| `bg=` | الوصف | لون النص الافتراضي | لون التمييز `*…*` |
|---|---|---|---|
| `dark` | أسود، توهج أحمر أعلى المنتصف، أرضية شبكية حمراء بمنظور، جمرات تطير | أبيض كروم | أحمر |
| `red` | أشعة شمسية (sunburst) تدور ببطء، أرضية حمراء فاتحة | فضي | أسود |
| `cream` | كريمي مع دوائر متحدة المركز باهتة | أسود لامع | أحمر |
| `camera` | كريمي مع زوايا إطار كاميرا، و`● REC`، وعدّاد وقت | أسود | أحمر |
| `image` | صورة مولّدة مجاناً أو ملف صورة، مع زوم بطيء (كين بيرنز) وتظليل داكن بتوهج أحمر | أبيض | أحمر (أسود مع `tint=red`) |

**خلفيات الصور (`bg=image`)**:
- `prompt="..."`: وصف الصورة، والأفضل بالإنجليزية. تُولَّد **مجاناً بدون حساب** عبر Pollinations
  (`scripts/imagegen.py`) وتُحفظ في `images/` بجانب الستوري بورد، فلا تتولد مرة ثانية.
- `image=photo.jpg`: صورة موجودة بدل التوليد.
- `tint=`: بدونها تظليل داكن مع توهج أحمر، و`red` أبيض وأسود بصبغة حمراء، و`none` الصورة كما هي.
- `seed=`: رقم يغيّر نتيجة الصورة لنفس الوصف.
- إعدادات عامة: `@ image_style="..."` أسلوب يُضاف لكل وصف، و`image_model=` اسم النموذج.
- الخدمة المجانية أضعف من Firefly وأحياناً مشغولة، والأداة تعيد المحاولة تلقائياً.
  تحتاج السماح بالموقع `image.pollinations.ai` في الشبكة (مضاف في هذه البيئة).
- استعمل الصور في **مشاهد قليلة** (الافتتاحية، اللحظات العاطفية، الختام)، وأبقِ الباقي بالخلفيات
  الأربع، حتى تبقى هوية "ضربة" واضحة.

**العناصر المرافقة (props)**:
- `chat`: نافذة محادثة داكنة ("وش نسوي اليوم؟") يُكتب فيها الطلب حرفاً بحرف، أو يُرفق فيها ملف.
- `phone`: جوال يعرض صفحة المتجر، أو لوحة تعليقات يُكتب فيها "سكيل"، أو رسالة خاصة فيها رابط.
- `cards`: بطاقات صغيرة لمشاهد سابقة تصطف، وتعبّر عن "ترتيب اللقطات".

## ٣) طريقة المونتاج (أهم قسم)

1. **الكلمة تظهر لحظة نطقها بالضبط**، لا قبلها ولا بعدها. الصوت هو الذي يقود المونتاج.
2. **دخول الكلمة "ضربة"**: تبدأ بحجم ×1.75 مع ضبابية وتنزل من فوق، ثم تستقر بارتداد خفيف
   (overshoot) خلال 0.2 ثانية.
3. **الكلمات تتراكم** داخل المشهد سطراً تحت سطر، من 1 إلى 4 أسطر وكلمتين أو ثلاث في كل سطر،
   ثم **قطع**.
4. **إيقاع القطع**: كل **1.75 ثانية في المتوسط**؛ أقصره 0.5 ثانية في افتتاحية "ضربة / وحدة / تكفي"،
   وأطوله نحو 3.5 ثانية في الجمل الطويلة. الفيديو المرجعي فيه 26 مشهداً في 45 ثانية.
5. **كل قطع حاد** يصحبه وميض أبيض (0.09 ثانية)، وزوم دخول، وضبابية حركة، وصوت **whoosh**.
6. **كاميرا حيّة**: زوم بطيء للداخل طوال المشهد (+7%)، وارتجاج قصير على الكلمات القوية `fx=shake`.
7. **التمييز اللوني**: كلمة واحدة في المشهد، وهي الكلمة المفتاحية (الحين؟ / سكيل / بمتجري / فوراً)،
   تكون حمراء وأكبر (`+*كلمة*`)، ومعها صوت **hit** منخفض.
8. **الافتتاحية بانفجار**: حلقة حمراء متوهجة مع شرر (`fx=ring,sparks`). والكلمات الأولى من مقطع
   واحد ومن غير تمهيد.
9. **القطع الناعم** `cut=soft`: يتغير النص ويبقى العنصر في مكانه بلا وميض، مثل مشاهد الجوال في
   النهاية.
10. **الختام**: يُكرر الجوال في المشاهد الأخيرة، ثم تظهر الكلمة الأخيرة وحدها كبيرة وحمراء مع شرر.

## ٤) الصوت وطريقة الإلقاء، ووصفة النص

**الصوت المرجعي** (مقيس):
- رجل بالغ، طبقة متوسطة (الوسيط 129Hz).
- **مدى نغمي واسع**، من 90 إلى 216Hz، أي ×2.4. هذا أداء حماسي تمثيلي وليس قراءة مسطحة.
- **السرعة**: نحو 2.1–2.4 كلمة في الثانية، وهي سريعة للعربية.
- **بلا وقفات تقريباً**: أطول صمت في الفيديو كله 0.6 ثانية، في النهاية.
- **مضغوط وعالٍ**: -14 LUFS، بمدى ديناميكي 2.5 LU فقط، أي صوت إعلاني "في وجهك".
- مع موسيقى ومؤثرات تحته.

**طريقة الإلقاء**:
- لهجة سعودية عامية واثقة، كأنه يكلّم صاحبه: «ترى»، «السالفة»، «وش»، «ودّك»، «هالسكيل»، «تكفي».
- ضغط قوي على الكلمة المفتاحية في آخر كل جملة.
- الأسئلة البلاغية بنبرة صاعدة: «قدامك الحين؟».
- التعداد السريع بـ «ولا… ولا…» لنفي الاعتراضات.
- النهاية بكلمة واحدة حاسمة: «فوراً».

**وصفة النص**، وهي تركيبة الإعلان المرجعي، وتُعاد بأي موضوع:

| # | المرحلة | المدة | مثال من المرجع |
|---|---|---|---|
| 1 | **خطّاف** من 2–3 كلمات | 0–1.5ث | ضربة وحدة تكفي. |
| 2 | **مفاجأة/كشف** | 1.5–8ث | المونتاج اللي جالس قدامك الحين؟ صدّق أو لا، معمول بالكامل داخل Claude. |
| 3 | **قتل الاعتراضات** بـ «ترى ما فيه… ولا… ولا…» | 8–17ث | ترى ما فيه أي اشتراكات خارجية، ولا وجع راس MCP، ولا منصات تقعد تسحب منك كريدتات… |
| 4 | **السر** | 17–23ث | السالفة كلها سكيل بنيتها وطوّرتها بنفسي. الشغل صار بينك وبينه مباشرة. |
| 5 | **كيف تشتغل** بخطوات مع عنصر UI | 23–36ث | تعطيه الفكرة أو السيناريو، والسكيل تطلّع لك ترتيب اللقطات وحركة المونتاج… |
| 6 | **CTA** بكلمة في التعليقات | 36–46ث | السكيل هذي جاهزة بمتجري. إذا ودّك فيها اكتب لي بالكومنتات «سكيل» ويوصلك الرابط على الخاص فوراً. |

النص الكامل للمرجع موجود في `reference/analysis.md`.

## ٥) صيغة الستوري بورد

```text
# تعليق
@ music=bgm.mp3 music_volume=0.12           ← إعدادات عامة (اختيارية): music=auto · pace=2.0 · sfx=no

[bg=dark fx=ring,sparks] +ضربة                ← سطر = مشهد = قطع
[bg=red fx=shake] +*وحدة*
[bg=camera] قدامك / +*الحين؟*               ← / سطر جديد داخل المشهد
[bg=cream] -داخل / {كلود}<+Claude>          ← {يُنطق فقط} <يُكتب فقط>
[bg=dark prop=chat question="وش نسوي اليوم؟" text="صمّم لي…"] تعطيه الفكرة / أو السيناريو
[bg=dark prop=phone app="متجري" hero="ضربة" comment="سكيل"] اكتب لي بالكومنتات / +*«سكيل»*
[bg=dark prop=phone … cut=soft] +*فوراً.*
```

| علامة | المعنى |
|---|---|
| `*كلمة*` | لون التمييز، ويمكن أن يمتد على عدة كلمات: `*يبي الحين؟*` |
| `+` / `-` | تكبير ×1.35 / تصغير ×0.7، ويمكن تكرارها: `++` |
| `.` `،` `:` `!` | تُنطق ولا تُكتب. `؟` و`«»` تُكتب |
| `fx=` | `ring` · `sparks` · `slash` (خط ليزر) · `shake` |
| خصائص المشهد | `y=` موضع النص بالبكسل من 1920 · `size=` حجم الخط الأساسي (165، أو 118 مع عنصر) · `push=` قوة الزوم · `tilt=` ميلان · `reflect=no` · `cut=soft` |
| `prop=chat` | `question` `text` `file` `reply` `model` `header` |
| `prop=phone` | `app` `hero` `title` `desc` `button` `comment` `tabs` · رسالة خاصة: `dm_text` `dm_title` `dm_link` `dm_hero` |
| `prop=cards` | `items="أ|ب|ج|د"` |
| كل العناصر | `prop_y=` |

إذا لم تحدد `bg` تتناوب الخلفيات تلقائياً: dark ← red ← cream ← dark ← red ← camera.

**قواعد ذهبية للستوري بورد**:
- لا تزد عن 9 كلمات في المشهد، ولا عن 4 أسطر.
- كلمة مميزة واحدة في كل مشهد.
- لا تكرر نفس الخلفية مرتين متتاليتين إلا مع `cut=soft` أو مع نفس العنصر.
- المشهد الأول كلمة واحدة فقط.

## ٦) ملاحظات وأعطال معروفة

- **السطر الطويل يُصغَّر تلقائياً** ليبقى داخل 980px، لكن الأفضل تقسيمه بـ `/`.
- **في حاوية Claude السحابية**: edge-tts محجوب (WebSocket)، وكذلك تنزيل نماذج whisper
  (huggingface)، وتنزيل ملفات storage.moknah.io. لذلك استخدم صوتاً يرفعه المستخدم، أو التوقيت
  بالطاقة، أو `--words`. كل هذا يعمل على جهاز المستخدم وعلى GitHub Actions.
- **عند الرندر بصوت المرجع** (فيه موسيقى ومؤثرات) استخدم `--no-sfx`.
- **الإعادة الكاملة للمرجع للاختبار**:
  `python3 scripts/salam.py make examples/darba-ad.board.txt reference/reference.mp4 --words examples/darba-ad.words.json -o out.mp4 --no-sfx`
