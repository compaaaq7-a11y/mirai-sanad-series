# الـ 6 أوامر — طريقة التسطيب

كل ملف zip فيه أمر واحد (Skill):

| الأمر | بيعمل إيه | مثال |
|---|---|---|
| `/calligraphy` | خط عربي بيكتب نفسه | `/calligraphy حيّاك الله` |
| `/minimal` | أي فكرة في موشن مينيمال | `/minimal خطوة خطوة` |
| `/breakdown` | منظر مفكّك لأي حاجة | `/breakdown مبخرة` |
| `/map-route` | مسار متحرك على خريطة 3D | `/map-route من البيت للدوام` |
| `/graph` | عدّاد + منحنى نمو | `/graph من 0 لـ 100 ألف` |
| `/dots` | صورة من آلاف النقط | `/dots خيل عربي` |

## في Claude (الموقع أو التطبيق)
1. افتح **Settings ← Capabilities ← Skills**.
2. اضغط **Upload skill** وارفع ملف الـ zip. كرّرها مع كل ملف من الـ 6.
3. افتح شات جديد واكتب الأمر وبعده الموضوع، مثلاً `/breakdown سماعة`.

## في Claude Code
فك ضغط كل ملف جوّه `~/.claude/skills/`، يعني كل أمر في فولدر باسمه وجواه `SKILL.md`.

> النتيجة بتطلع ملف HTML متحرك بمقاس الريلز 9:16. تقدر تسجّل الشاشة وتنزّله على طول، أو تغيّر الألوان لما تكتب مثلاً «بألوان براند بتاعي أزرق وأبيض».
